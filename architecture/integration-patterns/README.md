# 🔄 Integration Patterns

Central de estudos sobre **padrões de integração de sistemas**.

Esta seção reúne estratégias para comunicação entre aplicações, serviços, componentes e sistemas externos.

---

## 🌐 API Patterns

* API Gateway
* Backend for Frontend (BFF)
* REST
* Request / Response
* Aggregator

---

## 📨 Messaging Patterns

* Message Broker
* Publish / Subscribe
* Point-to-Point
* Message Queue
* Event Notification
* Event-Carried State Transfer

---

## ⚡ Resilience Patterns

* Retry
* Exponential Backoff
* Timeout
* Circuit Breaker
* Bulkhead
* Rate Limiting

---

## 🛡️ Reliability Patterns

* Idempotency
* Dead Letter Queue
* Poison Message
* Message Deduplication
* Failure Handling

---

## 🔄 Distributed Transaction Patterns

* Transactional Outbox
* Saga
* Choreography
* Orchestration
* Eventual Consistency

---

## 🎯 Objetivos

* compreender padrões de integração;
* projetar comunicação entre sistemas;
* reduzir acoplamento;
* lidar com falhas;
* garantir processamento confiável;
* trabalhar com sistemas distribuídos.
