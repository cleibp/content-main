# 🧱 Clean Architecture

Central de estudos sobre **Clean Architecture** e organização de sistemas de software.

A Clean Architecture busca separar responsabilidades e manter as regras de negócio independentes de frameworks, interfaces e detalhes de infraestrutura.

---

## 🗺️ Conteúdos

### 🧠 Core Concepts

* Entities
* Use Cases
* Application Rules
* Business Rules
* Boundaries
* Dependency Rule

### 🔄 Dependency Management

* Dependency Inversion
* Dependency Injection
* Abstractions
* Interfaces
* Inversion of Control

### 🏛️ Layers

* Domain
* Application
* Interface Adapters
* Infrastructure

### 🧪 Testability

* Unit Testing
* Integration Testing
* Test Isolation
* Dependency Substitution
* Test Doubles

### 🔌 Infrastructure

* Database
* External APIs
* Messaging
* Frameworks
* Persistence
* Configuration

---

## 🎯 Objetivos

* compreender os princípios da Clean Architecture;
* reduzir acoplamento;
* separar responsabilidades;
* proteger regras de negócio;
* aumentar testabilidade;
* facilitar evolução do software.
