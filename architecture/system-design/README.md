
# 📐 System Design

Central de estudos sobre **System Design** e projeto de sistemas de software.

Esta seção reúne conceitos utilizados para analisar requisitos, definir componentes, projetar sistemas distribuídos e avaliar decisões arquiteturais.

---

## 🗺️ Conteúdos

### 📋 Requirements

* Functional Requirements
* Non-Functional Requirements
* Business Requirements
* Technical Requirements
* Constraints
* Assumptions

### 📈 Scalability

* Vertical Scaling
* Horizontal Scaling
* Load Balancing
* Stateless Services
* Caching
* Database Scaling
* Sharding
* Replication

### ⚡ Performance

* Latency
* Throughput
* Response Time
* Bottlenecks
* Capacity
* Performance Testing

### 🛡️ Reliability

* Fault Tolerance
* High Availability
* Redundancy
* Failover
* Disaster Recovery
* Recovery Time Objective
* Recovery Point Objective

### 🌐 Distributed Systems

* Distributed Communication
* Network Failures
* Partial Failures
* Consistency
* Availability
* Partition Tolerance
* CAP Theorem
* Eventual Consistency

### ⚖️ Trade-offs

* Consistency vs Availability
* Performance vs Consistency
* Complexity vs Scalability
* Cost vs Reliability
* Synchronous vs Asynchronous Communication

---

## 🎯 Objetivos

* aprender a projetar sistemas;
* compreender requisitos não funcionais;
* analisar escalabilidade e disponibilidade;
* identificar gargalos;
* avaliar trade-offs;
* projetar sistemas distribuídos.
