# 🏗️ Architecture

Central de estudos, referências e práticas relacionadas à **Arquitetura de Software**.

Esta seção reúne conceitos e abordagens utilizados para projetar sistemas organizados, desacoplados, evolutivos, resilientes e escaláveis.

---

## 🗺️ Conteúdos

### 📐 System Design

Conceitos e práticas para projetar sistemas considerando requisitos funcionais e não funcionais.

* Requirements
* Scalability
* Availability
* Reliability
* Performance
* Capacity Planning
* Resilience
* Trade-offs

---

### 🧱 Clean Architecture

Princípios para estruturar sistemas com baixo acoplamento e separação clara de responsabilidades.

* Entities
* Use Cases
* Interface Adapters
* Infrastructure
* Dependency Rule
* Dependency Inversion
* Boundaries
* Separation of Concerns


---

### 🧠 Domain-Driven Design

Abordagem para modelagem de software orientada ao domínio do negócio.

* Domain
* Entity
* Value Object
* Aggregate
* Repository
* Domain Service
* Application Service
* Bounded Context
* Ubiquitous Language
* Domain Events


---

### 🔗 Microservices

Conceitos e práticas relacionados à construção e evolução de sistemas baseados em serviços independentes.

* Service Boundaries
* Service Communication
* Service Discovery
* Configuration
* Data Ownership
* Resilience
* Scalability
* Deployment
* Observability

---

### ⚡ Event-Driven Architecture

Arquiteturas baseadas em eventos para comunicação assíncrona e desacoplamento entre componentes e serviços.

* Events
* Producers
* Consumers
* Event Brokers
* Event Streaming
* Eventual Consistency
* Event Sourcing
* CQRS
* Message-Driven Architecture

---

### 🎨 Design Patterns

Soluções reutilizáveis para problemas recorrentes de design de software.

* Creational Patterns
* Structural Patterns
* Behavioral Patterns

---

### 🏛️ Architectural Patterns

Modelos recorrentes utilizados para estruturar sistemas e suas responsabilidades.

* Layered Architecture
* Hexagonal Architecture
* Onion Architecture
* Clean Architecture
* Modular Monolith
* Microservices
* Serverless Architecture
* Event-Driven Architecture

---

### 🔄 Integration Patterns

Padrões utilizados para integração e comunicação entre sistemas e componentes.

* API Gateway
* Backend for Frontend (BFF)
* Message Broker
* Publish / Subscribe
* Request / Response
* Asynchronous Messaging
* Retry
* Dead Letter Queue
* Circuit Breaker
* Outbox Pattern
* Saga Pattern

---

### 📋 Architecture Decision Records

Documentação das decisões arquiteturais relevantes tomadas durante o desenvolvimento dos projetos.

* Context
* Problem
* Decision
* Alternatives
* Consequences
* Trade-offs
