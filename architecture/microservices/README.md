# 🔗 Microservices

Central de estudos sobre **Arquitetura de Microsserviços**.

Esta seção aborda conceitos, benefícios, desafios e padrões relacionados à construção de sistemas compostos por serviços independentes.

---

## 🗺️ Conteúdos

### 🧩 Service Boundaries

* Service Decomposition
* Business Capabilities
* Bounded Context
* Service Ownership
* Data Ownership

### 🌐 Communication

* REST
* gRPC
* Messaging
* Event-Driven Communication
* Synchronous Communication
* Asynchronous Communication

### 🗄️ Data

* Database per Service
* Data Ownership
* Distributed Transactions
* Eventual Consistency
* Data Synchronization

### 🛡️ Resilience

* Retry
* Timeout
* Circuit Breaker
* Bulkhead
* Rate Limiting
* Fault Isolation

### 📊 Observability

* Logging
* Metrics
* Tracing
* Correlation ID
* Distributed Tracing

### 🚀 Deployment

* Independent Deployment
* Containers
* Kubernetes
* Service Discovery
* Configuration Management

---

## 🎯 Objetivos

* compreender microsserviços;
* definir limites de serviços;
* compreender comunicação distribuída;
* lidar com falhas;
* trabalhar com consistência eventual;
* projetar serviços independentes.
