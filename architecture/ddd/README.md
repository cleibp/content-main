# 🧠 Domain-Driven Design

Central de estudos sobre **Domain-Driven Design (DDD)**.

DDD apresenta conceitos e práticas para compreender, modelar e implementar sistemas orientados ao domínio do negócio.

* compreender o domínio do negócio;
