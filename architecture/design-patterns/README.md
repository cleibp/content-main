# 🎨 Design Patterns

Central de estudos sobre **Design Patterns**.

Design Patterns são soluções recorrentes para problemas comuns de design de software.

---

## 🏭 Creational Patterns

Padrões relacionados à criação de objetos.

* Singleton
* Factory Method
* Abstract Factory
* Builder
* Prototype

→ [Acessar Creational Patterns](./creational/README.md)

---

## 🧱 Structural Patterns

Padrões relacionados à composição de objetos e estruturas.

* Adapter
* Bridge
* Composite
* Decorator
* Facade
* Flyweight
* Proxy

→ [Acessar Structural Patterns](./structural/README.md)

---

## 🔄 Behavioral Patterns

Padrões relacionados à comunicação e comportamento dos objetos.

* Chain of Responsibility
* Command
* Iterator
* Mediator
* Memento
* Observer
* State
* Strategy
* Template Method
* Visitor

→ [Acessar Behavioral Patterns](./behavioral/README.md)

---

## 🎯 Objetivos

* compreender problemas recorrentes de design;
* conhecer soluções reutilizáveis;
* identificar quando utilizar cada padrão;
* compreender trade-offs;
* aplicar padrões em sistemas reais.
