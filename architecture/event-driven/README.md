# ⚡ Event-Driven Architecture

Central de estudos sobre **Event-Driven Architecture (EDA)**.

Esta seção aborda arquiteturas baseadas em eventos e comunicação assíncrona entre componentes e serviços.

---

## 🗺️ Conteúdos

### 📣 Events

* Domain Events
* Integration Events
* Event Producers
* Event Consumers
* Event Contracts
* Event Schema

### 📨 Messaging

* Message Broker
* Queue
* Topic
* Publish / Subscribe
* Message Delivery

### 🔄 Event Processing

* Event Processing
* Event Streaming
* Consumer Groups
* Ordering
* Partitioning

### 🧩 Consistency

* Eventual Consistency
* Distributed State
* Synchronization
* Read Models

### 🏛️ Advanced Concepts

* Event Sourcing
* CQRS
* Transactional Outbox
* Saga
* Idempotency
* Dead Letter Queue

### 🛡️ Reliability

* Retry
* Backoff
* Failure Handling
* Duplicate Messages
* Poison Messages

---

## 🎯 Objetivos

* compreender arquiteturas orientadas a eventos;
* trabalhar com comunicação assíncrona;
* reduzir acoplamento;
* compreender consistência eventual;
* projetar sistemas resilientes;
* aplicar mensageria em sistemas distribuídos.
