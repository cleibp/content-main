
# ⚙️ Engineering

Princípios, práticas e fundamentos utilizados para construir software de qualidade, sustentável e evolutivo.

---

## 📚 Conteúdos

### 🧱 Object-Oriented Programming

Fundamentos da programação orientada a objetos.

* Classes e objetos
* Encapsulamento
* Abstração
* Herança
* Polimorfismo
* Composição
* Associação
* Agregação
* Coesão e acoplamento

---

### ✨ Clean Code

Práticas para escrever código legível, simples e sustentável.

* Naming
* Functions
* Classes
* Error Handling
* Comments
* Code Structure
* Code Smells

---

### 🧩 SOLID

Princípios de design para melhorar a organização e manutenção do software.

* Single Responsibility Principle
* Open/Closed Principle
* Liskov Substitution Principle
* Interface Segregation Principle
* Dependency Inversion Principle

### 📐 Software Principles

Princípios gerais para desenvolvimento de software.

* DRY — Don't Repeat Yourself
* KISS — Keep It Simple
* YAGNI — You Aren't Gonna Need It
* WET — Write Everything Twice
* TDA — Tell, Don't Ask
* Separation of Concerns
* Law of Demeter
* Composition Over Inheritance

---

### 🧪 Testing

Fundamentos e estratégias de testes de software.

* Unit Testing
* Integration Testing
* End-to-End Testing
* Test Doubles
* TDD
* BDD
* Test Pyramid

---

### 🔨 Refactoring

Técnicas para melhorar a estrutura interna do código sem alterar seu comportamento.

* Code Smells
* Extract Method
* Extract Class
* Rename
* Move Method
* Replace Conditional
* Technical Debt

### 👀 Code Review

Práticas para análise e melhoria contínua do código.

* Readability

* Design
* Testing
* Security
* Performance
* Standards
* Technical Debt

### ⚡ Performance

Fundamentos relacionados ao desempenho de aplicações.

* Latency

* Scalability

### 🔐 Security

Princípios fundamentais de segurança no desenvolvimento de software.
